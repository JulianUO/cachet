# Status page

The public status page is the visitor-facing surface of Cachet.

## What visitors see

- Overall system banner (operational / degraded / major outage / maintenance)
- Component groups and components with current status
- Optional **90-day uptime history** bars (when enabled in settings)
- Incident timeline and scheduled maintenance
- Subscriber signup (when notifications are enabled)

## Operator setup

1. In the dashboard: **Settings → Manage Cachet** — site name, about text, incident history window, graphs, etc.
2. Create **component groups** and **components**.
3. Publish **incidents** and **schedules** as needed.
4. Optionally enable **display system status** so the 90-day graphic appears (see [History & calendar](history-calendar.md)).
